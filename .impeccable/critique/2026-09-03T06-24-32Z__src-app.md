## Design specificity

LLM: Authored for this product. Walnut/paper/copper printouts, mono claims vs sans chrome, SVG-as-sacred-object, and kind cues are not a generic dark dashboard. Operate chrome is more interchangeable: 13 equal sections, chip encyclopedias, always-on Create fetch.

Deterministic scan: CLI `detect.mjs` on src/app + src/components exited 0 with 0 findings. Runtime overlay (Playwright, live-server :8400, then stopped) claimed 23–95 anti-patterns per page. Agreed with the LLM on `/new` first-column overflow (editor vs sticky preview). Overlay low-contrast (copper on walnut 4.4:1 vs 4.5) is a real near-miss the LLM underweighted. Treated as false positives: `.truncate` ellipsis, 10px kind cues (DESIGN.md), kicker eyebrows (DESIGN.md), print-well shadow (DESIGN.md), overlay self-occlusion copy.

Visual overlays: injected in an automation tab, not a persistent [Human] Cursor tab. No overlay is left open for you.

## Priority issues

### [P1] Builder is 13 equal printouts plus an 8-control toolbar
Why: First paint is Untitled + empty SVG + optional Layers/Decisions/Screenshots. Copy embed stays disabled until a full publish.
Fix: Required cluster (title, handle, kind, desktop, distro) + Publish; collapse 08–13; overflow for paste/JSON; mobile preview above the form.
Suggested command: `/impeccable distill src/app/new` then `/impeccable onboard src/app/new`

### [P1] Explore at 390px is a facet encyclopedia; results start ~1300px down
Why: First screen is Kind + ~19 Desktop chips. No fetch in the thumb zone.
Fix: Kind + search + grid first; other facets in a closed Filters printout; full rail from lg.
Suggested command: `/impeccable adapt src/app/explore/page.tsx`

### [P1] Publish and ownership errors are not human
Why: `title: … · handle: …` Zod joins; public guest cookie is irreversible; Handle hint is the only warning. Sign-in talks about GITHUB_CLIENT_SECRET.
Fix: Field-level “Add a title / handle / desktop”; Publish line: this cookie owns the fetch until you sign in; map visibility to one sentence; rewrite sign-in.
Suggested command: `/impeccable clarify src/app/new` and `/impeccable harden src/app/sign-in`

### [P2] Copper Create fetch is global, including /new and fetch pages
Why: Rare Copper Rule: nav primary plus Publish or Copy markdown.
Fix: Nav primary only off the builder; on fetch, Copy markdown is the local primary.
Suggested command: `/impeccable layout src/components/site-header.tsx`

### [P2] Seven theme chips sit on the sacred card before the embed CTA
Why: spec.theme should recolor SVG, not dominate the printout.
Fix: Default on the card; default/dark/light plus More.
Suggested command: `/impeccable quieter src/app/f/[id]/page.tsx`
